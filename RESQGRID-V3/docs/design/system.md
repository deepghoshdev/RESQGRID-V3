# V3 design system
Fresh civic/operational direction: matte deep slate staff surfaces, light citizen surfaces, restrained blue actions and amber caution. Red identifies urgent danger or SOS. White headings and clear divider lines replace decorative effects. Typography uses a legible system sans stack, tabular operational values, 14px default labels/table text and 12px minimum supporting text; spacing follows 4/8/12/16/24/32px intervals.

Desktop staff layout: contextual left navigation, concise command header, strong page title, actionable queue/evidence panels and a large map. Citizen pages prioritize warnings and help above exploration. Mobile reduces columns, keeps navigation scrollable and primary controls readable. Cards have simple borders; buttons use text+icon and visible focus. Inputs have persistent labels, explicit validation and review steps. Tables expose relevant state and actions. Maps pair zones with a selectable equivalent list and describe illustrative overlays; basemap failure does not hide textual evidence. Charts include units/context; probabilities never imply certainty. Status labels combine text with color. Loading, empty, insufficient-data and unavailable integrations are explicit.

Accessibility targets: WCAG 2.2 AA, keyboard operation, native dialog focus behavior, reduced motion, visible focus, sufficient contrast, non-color state cues and reachable controls. This is a target requiring browser/manual verification, not a completed accessibility audit. CSS values are authoritative for this first UI; tokens in `tokens.json` record the matching palette and define consolidation direction for the next component pass.
